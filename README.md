# Muslimah Studio

Web estática preparada para publicar en Netlify mediante GitHub.

## Archivos
- `index.html`
- `styles.css`
- `script.js`

## Cómo subirla a GitHub
1. Abre tu repositorio.
2. Pulsa **Añadir archivo → Cargar archivos**.
3. Sube los tres archivos.
4. Confirma los cambios.

Netlify detectará el cambio y publicará la web automáticamente.

## Conectar Kit
En `index.html`, busca:

`<!-- Sustituye este formulario por el código EMBED de Kit -->`

Elimina el formulario de demostración y pega el código de inserción de tu formulario de Kit.

## Enlaces sociales
Busca la sección `social-links` en `index.html` y sustituye cada `href="#"` por el enlace real.
